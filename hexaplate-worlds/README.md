# Hexaplate Worlds
## 개요
이 디렉터리에는 헥사트라 내에 존재하는 각 헥사판(세계관)의 설정이 정리됩니다. 

- 각 하위 폴더는 하나의 헥사판을 의미합니다.
- 해당 디렉터리에 존재하는 설정, 캐릭터, 스토리 등 텍스트/콘텐츠는 각 세계 제작자에게 저작권이 있습니다. (All rights reserved.)
